Yes. Radix Popover focuses the first tabbable control on open (here, the blink count input). That is cancelled on this popover with `onOpenAutoFocus`.

```23:27:frontend/src/components/2-main/2-panel-controls/1-1-tree-options-popover.tsx
            <PopoverContent
                align="end"
                className="w-auto min-w-56"
                onOpenAutoFocus={(event) => event.preventDefault()}
            >
```

Focus stays on the settings button. Keyboard users can still Tab into the fields after it opens. Closing still returns focus to the trigger as usual.
